# 勉強銀行(NextK Lab)

集中ラボ・勉強銀行・受験スタディを1つにまとめた、勉強帳簿アプリです。
データはすべてブラウザの LocalStorage に保存されるので、サーバーやログインは不要です。

## 機能

- **表紙(ダッシュボード)**: レベル・連続記録・貯金残高(借金)・最新の模試結果・ToDo進捗をひと目で確認
- **集中ラボ**: ポモドーロ / 積み上げ / インターバルの3種タイマー、XPレベル(8段階)、バッジ、連続記録(ストリーク)、離席回数トラッキング、ブラウザ通知
- **勉強銀行**:
  - 1日の目標を設定し、毎晩自動で精算(超過分は貯金、未達分は借金)
  - 借金には1日ごとに約10%の利息
  - 貯金から指定額を借金の返済にあてられる(部分返済可)
  - 借金が「目標×3日分」を超えると1週間チャレンジが強制発動。7日間連続達成で借金帳消し、途中で途切れると1日目からやり直し
  - アイテムショップ(ストリーク復活・利息無効・見逃しチケット・XPブースト・休養券・離席帳消し券・目標変更券)を貯金で購入し、持ち物から使用可能
  - 通帳明細で入出金の履歴を確認できる
- **受験スタディ**: 模試の偏差値推移グラフ、科目別勉強時間、ToDoチェックリスト

## ローカルで動かす

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いてください。

## Vercelへのデプロイ

1. このフォルダをGitHubリポジトリにpushする
2. [Vercel](https://vercel.com) でアカウント作成 → 「Add New Project」→ リポジトリを選択
3. Framework Preset は自動で「Next.js」が選ばれます。設定変更は不要です
4. 「Deploy」を押すだけで公開されます

または Vercel CLI を使う場合:

```bash
npm install -g vercel
vercel
```

## データについて

- 保存先: ブラウザの LocalStorage(キー: `nextk-study-hub-v1`)
- 別の端末やブラウザとはデータは同期されません
- ブラウザの「サイトデータを削除」を行うと記録は消えるのでご注意ください
